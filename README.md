# 新品千川打法：立项 → 定位 → 测款 → 放量（开源方法）

> 用途：拿到一个新产品、还没写脚本前，先按本篇定方向。本篇只解决「做哪个、卖给谁、怎么测、怎么放」，具体脚本与拍摄见后文各节。方法来自开源 marketing / ads skill，阈值为社区经验，非千川官方标准；跨境 TikTok Shop 的计划结构可借鉴，本地千川以后台与官方规则为准。

## 一、先建产品底卡（product-marketing）

拿到新品先填一张底卡，后面所有研究和脚本都从这里取事实；资料没有的项先留空，不替它补全、不猜。

| 栏目 | 填什么 |
|-|-|
| **产品概述** | 一句话是什么、属于哪个「货架」品类、商业模式与定价 |
| **目标受众** | 谁买、主要使用场景、雇它来完成的任务（JTBD） |
| **痛点** | 客户找到你之前的核心难题、现有方案为何不够、代价（时间/钱/机会）、情绪张力 |
| **竞品格局** | 直接 / 间接 / 替代方案各是谁、各自差在哪 |
| **差异化** | 你独有的能力、做法不同在哪、为什么对客户更好 |
| **异议与反人群** | 最常听到的 3 条顾虑及回应；谁不适合买（anti-persona） |
| **客户语言** | 客户原话怎么描述问题、怎么描述你的方案；该用 / 该避的词 |
| **利润底线** | 保本 ROAS / CPA 硬线、预算与节奏、什么转化算数（见第五节） |

来源：coreyhaines31/marketingskills · product-marketing。

## 二、人群与痛点从真实语言来（customer-research）

- 不要把品牌自己写的卖点当成用户真在意的；从评论、访谈、问卷、客服记录、社区讨论里挖用户原话。
- 痛点 / 触发 / 期望结果 / 异议 / 考虑过的替代，分开记录；客户原话（「金句」）留作文案素材。
- 画像（persona）要有证据门槛：同一人群至少 5 条独立来源（访谈 / 评论 / 社区帖）再立像；新品无评论时，用竞品评论、同类目商品评价、相邻品牌人群做「代理源」，并标注为待验证，拿到一手评价后替换。
- 区分「品牌想说」与「用户真说」；两者矛盾处标出。

来源：coreyhaines31/marketingskills · customer-research。

## 三、竞品同维比较（competitor-profiling）

- 把竞品放进同一组字段比较：卖给谁、什么场景、主打什么、拿什么证明、希望你下一步做什么；页面没写的不补。
- 三层分开：观察（来源 + 日期）/ 推断（标注置信度）/ 含义（作为选项而非结论）。
- 不臆测动机（「他涨价是为了向上走」是猜测，不写）；竞品信息标日期快照，过期重核；不点名贬低。

来源：coreyhaines31/marketingskills · competitor-profiling。

## 四、投放测款结构（tiktok-shop-ads）

- 先选高潜商品、定目标（转化为主），再搭计划结构；冷启动自动出价收集数据，日预算从保守起步，数据充分后转手动。
- 人群扩展顺序：核心已转化人群 → 购买者相似人群（lookalike）→ 更宽兴趣定向 → 动态商品重定向。
- 素材测试：首批 A/B 3–4 个变体，分开测钩子、CTA、视频时长（15 / 30 / 60s），对比 UGC 与精拍；一次只变一个变量。
- 放量：跑赢的计划预算每次 +20–30%，不一次性猛加；放量期守住目标 ROAS。
- 日常看 ROAS / CTR / CVR / CPA / 频次；日调预算、周测素材与人群、月看结构。

来源：nexscope-ai/eCommerce-Skills · tiktok-shop-ads（开源框架，非官方）。

## 五、保本线与利润底线（通用经营核算）

- 综合贡献毛利率 = 1 − 货品成本率 − 平台费率 − 达人佣金率 − 优惠券承担率 − 退款损耗率 − 履约成本率；可承受广告费率 ≈ 综合贡献毛利率；保本 gross ROAS = 1 ÷ 综合贡献毛利率。
- 平台 ROI 达标不等于订单赚钱：优惠券、佣金、退款、履约都要进账；低于保本线即标记，新料先小预算测试、设试投亏损上限与观察窗。
- 定价不锚竞品、不锚成本：价格落在「次优替代」与「客户感知价值」之间；首价是用来学习的赌注，先上架让真实买家反馈，再调整。（pricing skill 为 SaaS 订阅语境，仅借价值定价、首价学习思路，不搬 per-seat / 分层订阅。）

## 六、打法 → 脚本衔接

底卡填完、人群与保本线明确后，再进入：选钩子类型（黄金 3 秒钩子库）→ 选说服框架 → 按分镜模板出稿 → 过四维内容自检。

# 总体脚本结构：三段交叉组合

一条千川脚本由三部分构成：**开头前 3 秒 × 中间卖点 × 结尾引导**（青瓜传媒《千川素材脚本方法论》）。三部分各自有多种句式，交叉组合即可生成大量结构：开头选一种句式、卖点选一种表达、结尾选一种引导，拼成完整脚本。情绪曲线为「开头抓眼球 → 中间建信任 → 结尾促行动」。

| 段落 | 任务 | 要点 |
|-|-|-|
| **开头前 3 秒** | 截停拇指、证明与我有关 | 不做 logo 片头；第一帧是商品或痛点画面；一次出 6–10 版不同钩子类型做 A/B |
| **中间卖点** | 把卖点转成可感知的利益点与证明画面 | 不说参数说体验；每个卖点配「说 + 证明」，光说不演不算卖点 |
| **结尾引导** | 促单收口 | 千川素材原生化后尾部引导逐步软化，不做鲁班式硬指令 |

# 说服公式与叙事框架（开源 copywriting skill）

「总体脚本结构」管开头×卖点×结尾的段落分配；本节补「整条片子用什么说服逻辑推进」。以下框架来自开源 copywriting 技能收录的通用营销公式，只作说服骨架——框架不替代证据，功效、数字、背书仍须有据，写完过四维自检。

## 选型表：什么产品选哪个框架

| 框架 | 节拍顺序 | 最适合 | 千川短视频用法 |
|-|-|-|-|
| **PAS**（Problem-Agitate-Solution） | 点痛点 → 放大后果 → 给解法 | 痛点驱动、冷受众、日常快消 | 30s 标准带货主线：先戳日常麻烦，再说不解决会怎样，产品出场做解法 |
| **BAB**（Before-After-Bridge） | 现状困境 → 使用后理想 → 产品是桥 | 改造型、效果前后可感、短广告 | 15s 种草：先摆现状痛点，再上使用后画面，产品就是那座桥 |
| **AIDA**（Attention-Interest-Desire-Action） | 注意 → 兴趣 → 欲望 → 行动 | 新品亮相、建立认知、结构化讲解 | 60s 测评/讲解：抓注意 → 讲为什么与我相关 → 画使用后结果 → 收口行动 |
| **FAB**（Feature-Advantage-Benefit） | 功能 → 优势 → 利益 | 技术 / 功能 / 参数型产品 | 每个卖点一行：说功能 → 它带来什么 → 所以你能得到什么 |
| **4Ps**（Promise-Picture-Proof-Push） | 承诺 → 画面 → 证明 → 推动 | 高客单、需重证据 | 高客单 / 复杂品：先立承诺，描绘结果，用证据证明，再推动下单 |
| **PASTOR**（Problem-Amplify-Story/Solution-Offer-Response） | 问题 → 放大 → 故事解法 → 报价 → 回应 | 长文案 / 视频销售信、复杂 offer | 60s+ 深度讲解；短视频一般不全用，只借「问题-放大-故事」前段 |

## 短视频内可直接套用的精简句式

- **BAB（3 句）**：[当前困境]。[使用后的理想状态]。[产品就是通往那里的桥]。
- **AIDA（4 句）**：[抓注意的主张]。[与你相关的细节]。[值得想要的结果]。[明确的行动]。
- **PAS（3 句）**：[具体痛点]。[不解决会怎样]。[产品是解法]。
- **FAB（一个功能一句）**：[功能]，也就是[优势]，所以你能[利益]。

## Feature → Benefit：把功能翻译成用户利益

不要直接念参数 / 成分（资料里有也要翻译成体验），句式：「[Feature 功能]，which means（也就是）[Advantage 优势]，so you can（所以你能）[Benefit 利益]」。例：面料含 XX% 纤维（功能）→ 上手更挺括（优势）→ 洗后不易塌、穿久依然有型（利益）。与本库口径一致：不说参数说体验，每个利益点配一个可拍的证明画面；证据只取资料与实测，框架负责组织，不负责发明功效。

## 使用边界

- 框架选骨架不选台词：同一片子先定一个主框架，不混用两套节拍。
- 短素材（15s）优先 BAB / PAS；长讲解（60s）才用 AIDA / 4Ps / PASTOR。
- 框架不豁免合规：绝对化用语、虚假紧迫、未证实功效仍按四维自检与千川审核七类处理。

**来源（仅方法借鉴）：**[AgriciDaniel/claude-ads](https://github.com/AgriciDaniel/claude-ads) 的 references/copy-frameworks.md（AIDA / PAS / BAB / FAB / 4Ps 选型与平台模板）；社区 copy-frameworks 技能（AIDA / PAS / PASTOR / BAB / FAB / 4Ps 与 30 秒句式）；[Humblytics/ai-marketing-skills](https://github.com/Humblytics/ai-marketing-skills) copywriting（PAS / AIDA / BAB、Feature→Benefit 转换）。框架本身为公开通用营销方法。

# 黄金 3 秒钩子库

## 三拍结构（钩子不是一句俏皮话）

ClipForge（开源带货工具，原「带货剪手」）把钩子定义为一个 3 秒留人结构，而非一句俏皮话，按三拍设计：

1. **0–1s 截停**：强画面 / 强声音 / 强问题截停拇指，绝不放 logo 或空镜开场；
2. **1–3s 证相关**：让刷到的人立刻觉得「这跟我有关」；
3. **3–7s 接产品**：自然接到产品或效果，不硬转。

## 九种基础钩子类型（一次写 6–10 版）

以下 9 型来自开源仓库 `xianyu110/ecommerce-video-skills` 的 hook-3s-script 技能，示例为保温杯演示（未测数据不能用）。

| 类型 | 公式 / 机制 | 适用 | 句式示例 |
|-|-|-|-|
| **痛点提问** | 你是不是也……？从「用户什么时候会烦」出发，不从「产品有多好」出发 | 有明确日常痛点的品类 | 冰水不到中午就变温了？ |
| **反差** | 看着像 A，其实 B | 外形与预期有落差的商品 | 看着像普通水杯，晚上还能倒出冰块 |
| **结果先行** | 先给结果画面，再解释 | 效果可视、有前后差 | （先拍晚上倒出冰块）这是早上装的冰 |
| **数字** | N 个 / N 秒 / N 小时 | 有真实可测时长、数量的卖点 | 通勤包里放了 8 小时，一滴没漏 |
| **场景代入** | 当你在 X 的时候 | 使用场景明确的品类 | 健身完想喝口冰水的时候 |
| **错误示范** | 别再这样做了 | 存在常见错误用法时 | 别再往包里塞会漏的杯子了 |
| **对比** | 左边 vs 右边，对比用「普通款」不点名竞品 | 可同框对照的商品 | 左边普通杯，右边这只，同时装冰 |
| **第一人称安利** | 我……，个人使用经历起手 | UGC 可信口播 | 我换了三个杯子，最后留下这只 |
| **悬念** | 最后一个最关键，留信息差 | 要点可分点、可排序时 | 选保温杯看这 3 点，第 3 点最多人忽略 |

**钩子写法硬规范（hook-3s-script 原文）：**每条台词 ≤18 个汉字（中文约 4–5 字/秒，3 秒说完）；花字 ≤10 字，是台词的「标题版」，不是逐字重复；第一帧必须出现商品或痛点画面，不放 logo 片头；所有数字 / 效果必须有真实依据；不贬低具名竞品。

## 补充：信任型 / 社证型钩子（ClipForge 16 型）

在 9 型之外，ClipForge 的钩子库另列多类常规型与信任型，适合「全程夸」被观众识别为广告的反制场景。择要如下：

| 钩子名 | 机制（0–1s 截停 / 1–3s 证相关 / 3–7s 接产品） | 慎用 |
|-|-|-|
| **视觉冲击** | 第一帧上极致画面（爆浆 / 拉丝 / 脏净对比 / 微距质地），1–3s 点破与观众的关系 | 产品没有可视张力（纯数字 / 服务类）时不用 |
| **悬念提问** | 开口抛反常识 / 数字 / 身份问题，产品就是答案 | 问题太弱或答案太显然 |
| **反差对比** | 制造价格 / 效果 / 身份强反差画面或一句话 | 没有真实可证的反差，绝不虚标 |
| **痛点直击** | 一句话戳中具体痛 / 焦虑 / 后悔，放大日常场景 | 痛点太泛、谁都不疼 |
| **前后对比** | 先上「使用前」最糟状态，1–3s 切「使用后」反转 | 变化不明显或无法演示 |
| **声音钩子** | 第一秒一个抓耳声音（咔嚓 / 撕拉 / 爆开 / 水声）配画面 | 产品没有标志性声音 |
| **挑战质疑** | 「都说它好，我不信，今天实测」的质疑姿态 | 并没有真测试，别假装 |
| **身份共鸣** | 点名一个身份群体（打工人 / 宝妈 / 学生党），说出共同处境 | 身份和品类不搭 |
| **数字利益前置** | 开口甩具体数字（3 秒 / 省一半 / 一个动作），数字靠产品实现 | 数字虚标（违广告法） |
| **反常识意外** | 「你以为 A，其实 B」的认知颠覆 | 反常识太牵强 |
| **自曝反转** | 先自曝「差点翻车」的真实经历（差点退货 / 用错了 / 买亏过），转折点接产品 | 编造不存在的翻车经历，假故事一戳就穿 |
| **认缺点开场** | 开口先承认一个真实缺点，说明为何没挡住自己，再转核心优点 | 缺点是硬伤（安全 / 功效问题不能当话术） |
| **淘汰式测评** | 「买了 N 个退了 N-1 个」筛选结果前置，快闪被淘汰同类（不点名品牌） | 并没真横向用过多款（假测评踩合规红线） |
| **成本拆账** | 把价格拆成日常小数字（每天 / 每次多少钱），对比熟悉花销 | 数字虚标或价格不实（违广告法） |
| **评论回应** | 开场念一条评论区怀疑 / 提问，整条视频就是回答 | 只能用质疑 / 提问，不可换成夸赞式伪证言（平台判诱导） |
| **跟风真香** | 「刷到 N 次终于没忍住买了」的跟风者视角，给出态度反转 | 产品并没有社交热度，无风可跟显得假 |

## 行业实测钩子骨架（有米云六类目报告）

有米云《9 月六类目千川内容分析报告（黄金 3 秒 · 素材框架 · 种草 · 收割）》给出可直接套用的骨架：

- **价格锚定捡漏**：官方价 → 真没想到 → 数字。例：「本来预算二三千想换个大屏电视，真没想到这次捡了个漏」。
- **痛点设问 / 悬念**：具体窘境 → 反问。例：「见过阻燃的外壳吗？」
- **人群点名站队**：称呼 → 我懂你的坑。例：「选耳机总踩坑的宝宝可以看过来」。
- **否定纠错（叫停体）**：「别再给老公买冰丝内裤了」，否定旧做法再替代。
- **价格阶梯懊悔体**：「X 百你不买，我降了；你还等，我又降了」——损失厌恶 + 捡漏快感（真实降价才可讲）。

# 从产品资料到脚本内容

拿到一份产品资料后，先理解资料、再变成具体脚本，不走「先写词再找证据」的反向路径：资料里没有的功效、参数、价格、背书一律不写。本板块与「维度二：卖点有据」「维度三：资料齐全性」互为表里。

## 资料读取清单（8 项）

按清单逐项读资料，读到什么记什么，缺项进补料清单：

| 读取项 | 读什么 | 用途提示 |
|-|-|-|
| **品类 / 定位** | 属于什么品类、在同类里的位置、一句话定位 | 决定钩子语言与对比对象，不与品类常识打架 |
| **目标人群与痛点** | 谁在用、什么场景下被什么问题困扰、想得到什么结果 | 痛点是开头设问与中段卖点的来源 |
| **真实卖点与证据** | 资料明确写出的卖点，以及对应的检测、报告、实测、口碑证据 | 无证据的卖点不入选，见维度二 |
| **成分 / 参数** | 成分含量、规格、尺寸、材质等可核验数字 | 只讲资料与检测有的，数字不臆造 |
| **使用场景** | 在什么场合、什么人怎么用、前后状态变化 | 分镜画面取材于此，不说参数说体验 |
| **价格机制** | 日常价、活动价、赠品、库存与活动期限 | 须与商家实际活动一致后才写入；虚假限时限量见维度一 |
| **背书 / 认证** | 资质证书、检测报告、授权、销量与评价背书 | 不虚构、无授权不挪用；待补的列入清单 |
| **现有素材** | 产品图、实拍视频、检测件、用户反馈等可用材料 | 按 A/B/C/D 分级建档，缺等级先补料 |

## 资料核对与补料清单

- 逐项对照：资料没有的功效、参数、价格、背书、认证不写；写不出来的项不硬凑，宁可删。
- 缺什么列补料清单：缺检测报告补检测、缺实拍补拍摄、缺价格机制找商家确认、缺授权不挪用背书；清单交回用户补料后再写稿。
- 用户只给文案时，资料核对范围缩小为「文案是否有证据」，画面只按文案含义匹配，不替文案加功效。

## 资料到脚本的转化路径

按五步走，每一步都以上一步的资料结论为输入：

1. **资料**：按读取清单整理出事实库（卖点、证据、人群、场景、价格、素材）。
2. **人群痛点**：从事实库里提炼目标人群最在意的 1 个真实痛点，作为情绪入口。
3. **选钩子类型**：按痛点从「黄金 3 秒钩子库」选 1 个匹配类型，不硬套与品类无关的钩子。
4. **选 2–3 个最强卖点**：按「用户最在意 × 画面最好证明」排序，最强卖点放第 2–3 镜，对照「卖点挖掘清单（12 类）」。
5. **按分镜模板出稿**：套用 15 / 30 / 60 秒分镜模板逐镜落词，结尾按「结尾引导方式」收束，再走四维内容自检。

# 分镜脚本模板（15 / 30 / 60 秒）

以下结构来自 selling-point-storyboard 技能。规则：**一镜一信息**；每个卖点都要配证明画面（演示、细节、对比）；总台词字数 ≈ 时长 × 4.5（中文）；每镜台词 ≤2 句；时长超了删台词，不要把语速加快超过 +20%。

| 时长 | 结构（按顺序） | 镜数 |
|-|-|-|
| **15s** | 钩子(1) → 产品亮相(1) → 卖点 ×2–3(2–3) → 行动号召(1) | 5–6 镜（种草 / 主图视频） |
| **30s** | 钩子 → 痛点放大 → 产品亮相 → 卖点 ×3（每个「说 + 证明」）→ 使用场景 → 行动号召 | 8–10 镜（标准带货） |
| **60s** | 钩子 → 我的经历 → 开箱 → 卖点 ×3–4 演示 → 对比 → 缺点 / 适合谁 → 行动号召 | 14–18 镜（测评 / 讲解） |

## 分镜表栏目

每镜按下表填齐，先输出人看的 Markdown 表，再输出机器渲染用的 storyboard.json：

| 栏目 | 填什么 | 规范 |
|-|-|-|
| **时间** | 0–3s 等时间码 | 逐镜累计，总时长对得上目标 |
| **画面 / 素材** | 用哪张素材 / 要拍什么；缺素材标 TODO 并给拍摄或生成建议 | 素材只有一张图时，用不同 motion / fit 做两镜 |
| **台词（配音）** | 每镜 ≤2 句；只写已证实内容 | 总字数 ≈ 时长 ×4.5；不加速硬塞 |
| **字幕（高亮）** | 关键词用加粗标高亮 | 卖点镜头字幕别挡商品，可用 fit: blur、商品放上半屏 |
| **花字** | 可选；台词的标题版 | ≤10 字，不逐字重复台词 |
| **运镜** | punch 快推 / zoom_in 推近 / pan_down 下摇等 | 开场快推配合花字弹出 |

## 开箱模板 A（30–45s）

| # | 段落 | 画面 | 口播要点 |
|-|-|-|-|
| 1 | 钩子 | 快递盒 / 包装特写，手撕开 | 「花 X 天等来的，看看值不值」或痛点提问 |
| 2 | 包装 | 俯拍开盒，清单平铺 | 盒子里有什么（只说实际有的配件） |

## 对比评测模板 B（45–60s）

| # | 段落 | 画面 | 规则 |
|-|-|-|-|
| 1 | 钩子 | 两个产品并排 | 「同样装冰，8 小时后差多少？」（必须真的测过） |
| 2 | 选手介绍 | 并排平铺 | 竞品用「普通款 / 某价位常见款」，不点名贬低 |

| 7 | 总结表 | 对比卡 | ✔ / ✘ 表，赢的输的都写 |
| 8 | 适合谁 + 号召 | 结尾卡 | 诚实推荐 |

# 产品拍摄参考：发产品 → 出拍摄方案

> **用途：**用户发来产品资料后，按本节输出拍摄清单与分镜建议。只依据用户提供或可证实的信息出方案，不替用户改写文案、不编造功效/参数/价格/背书，对比不点名贬低竞品。

## 先定叙事脊柱（三选一）

拿到产品先判断它最适合哪种叙事主线，再列镜头；脊柱选错会导致镜头堆砌、卖点失焦。

| 脊柱 | 节拍顺序 | 适用产品 |
|-|-|-|
| **新品亮相 Product Launch**（默认） | 留白开场 → 主品立住主视角 → 材质/结构细节 → 自然产品动作 → 变体/配色关系 → 整品收尾落文案 | 耳机、手表、数码小配件、小家电、香氛等形态规整的单品 |
| **功能动作 Feature Touch** | 产品静止 → 交互触发 → 功能动作 → 细节放大 → 结果/感受 → 收尾 | 有清晰开合、旋转、磁吸、灯光变化、屏幕、折叠、起雾等可演示动作的产品 |
| **多色家族 Color Family** | 主色单独出场 → 辅助配色轻滑入 → 配色成序 → 材质结构统一 → 整套收尾 → 落文案 | 多色、多型号、多规格产品 |

## 六个必拍角度（机位不得重复）

按产品证据地图（product-proof map）备齐角度，每个镜头的机位必须与其他镜头不同；同一视角换房间不算不同机位。

| 角度 | 拍什么 | 景别 / 机位 |
|-|-|-|
| **Hero 主视角** | 最有吸引力的完整外观、轮廓、开场主画面 | 3/4 环境视角，平视，产品置于真实场景 |
| **手持出镜 in-hand** | 人手拿起、握持、操作，建立使用代入 | 中景，手持 |
| **纹理微距 close-up** | 材质、颗粒、反光、触感、接缝、Logo | 极端微距特写 |
| **使用演示 usage** | 真实使用过程，功能动作可视 | 中近景，跟拍 |
| **包装 packaging** | 开箱、包装质感、配件 | 俯视 / 侧面 |
| **前后对比 before/after** | 使用前后或效果对照（不点名贬低竞品） | 同机位对照 |

**规则：**两个镜头不能是同一机位同一视角；Hero 与 Spec（俯视 / 正侧面 / 平铺）须形成反差。

## 景别与运镜

- **景别：**特写（卖点/材质）、中景（动作/使用）、远景（环境/代入）搭配使用。
- **运镜：**推＝聚焦卖点，拉＝交代环境，摇/移＝展示全貌，环绕＝立体感，跟拍＝使用过程；一镜一个主动作，次要元素稍延迟进入。
- **节奏：**15s 约 2–3 个高点 + 2 个停顿（材质特写停留、收尾定格）；每拍只放一个主动作。

## 出稿流程（用户发产品后）

1. **收资料：**品类、形态、可演示动作、卖点（仅用户提供/可证实）、目标人群、时长、现有素材。
2. **定脊柱：**三选一并说明理由。
3. **列拍摄清单表：**镜号 / 时长 / 景别机位 / 画面动作 / 要拍到的证明 / 对应文案；缺的素材标 TODO。
4. **自检：**对照千川审核七类；不写未证实功效/参数/价格/背书；对比不点名贬低。

# 卖点挖掘清单（12 类）

中段卖点从以下 12 类挖掘，一个视频选 2–3 个最强、画面最好证明的，按「用户最在意 × 画面最好证明」排序，最强放第 2–3 镜。

| 类别 | 挖什么 | 方向提示 |
|-|-|-|
| **外观** | 形状、颜色、手感、颜值设计 | 微距 / 转台展示，配主观感受 |
| **材料** | 用料、面料、成分含量 | 只讲有检测或资料依据的，不臆造含量 |
| **工艺** | 制作工序、结构设计、细节做工 | 拆解 / 组装过程镜头 |
| **功能** | 能做什么、怎么用、解决什么问题 | 一句参数 + 一个可验证动作（拉扯 / 机洗 / 卷尺量） |
| **场景** | 在什么场合、什么人使用 | 场景化演示，不说参数说体验 |
| **人群** | 适合哪类人、不适合哪类人 | 点名身份，先说适合再说不适合 |
| **方法** | 怎么用更值、使用技巧 | 教程式种草，学会即种草 |
| **稀缺** | 限量、断码、批次少（须真实可举证） | 虚假限时限量属违规营销，见自检章节 |
| **地域** | 产地、源头、直供 | 源头实拍、档口直发，砍掉中间商话术 |
| **价格** | 价格锚点、买送件数、单次均摊 | 专柜价 / 线下价 → 到手价对比，数字必须真实 |
| **背书** | 销量、回购、评价、权威认证 | 只写可查证的；认证类需资质，不虚构 |
| **情怀** | 怀旧、治愈、价值观、故事感 | 情绪铺垫，商品是注脚 |

有米云原则：卖点全数字化、可演示——把「承托好」改写成「W 型软支撑 + 侧比加高 15 公分 + 上薄 0.2 下厚 2.2」，并配一个可执行验证动作；一句参数 + 一个动作，不要连续两句空形容词。

# 爆款拆片（拆解复刻）

爆款拆片来自开源仓库 viral-remake 技能：丢一条爆款带货视频（链接 / 转写 / 口述结构），拆出可复用骨架再换成自己的商品。**复刻的是结构与节奏，不是画面、配乐或台词原文**。若只有链接且看不了成片，请用户贴转写或口述 5-beat，不下载、不爬付费墙内容，也不假装已看过。

## 拆片要拆什么：8 维拆解对照表

按下表逐维记录原片，再逐维决定怎么换到本品；可复用的只有骨架，原片的台词、画面、品牌梗一律重写。

| 原片字段（拆解维度） | 拆解记录（原片） | 复刻到本品的做法 |
|-|-|-|
| **钩子类型** | 原片用了哪型钩子（痛点提问 / 反差 / 结果先行 / 数字 / 场景……），第一句话是什么 | 钩子类型可保留，台词全部重写；可交 hook-3s-script 出 6–10 版再选，≤18 字 |
| **前 3 秒画面** | 第一帧是什么、有没有商品、有没有花字弹出 | 只借「先出痛点 / 结果画面」的结构，画面用本品素材重拍或重出，不搬原片画面 |
| **节拍时间轴（5-beat）** | Hook → Problem → Solution → Proof → CTA 各段时间码 | 节拍骨架可保留，按本品目标时长重新分配时间 |
| **情绪温度** | 吐槽 / 安利 / 冷静测评 / 紧迫感 / 轻松，前后怎么转 | 情绪弧线可保留，语气按本品重写，不照搬原片口吻 |
| **花字 / 字幕节奏** | 关键词何时弹出、是否分句、高亮词是哪个 | 弹出节奏可保留，花字内容重写（≤10 字，不逐字重复台词） |
| **证明方式** | 演示 / 对比 / 细节特写 / 使用场景 / 口播数字 | 证明类型可保留；具体数字换成本品已证实卖点，优先可视化演示 |
| **CTA 形态** | 点链接 / 搜同款 / 评论区 / 关注，怎么收口 | 引导结构可保留，话术口语化重写，按结尾引导章节软化，不照抄 |
| **可复用 vs 不可复用** | 骨架✅；品牌专属梗❌；版权画面 / 配乐 / 原台词❌；无法证明的数据 / 认证 / 销量❌ | 不可复用项逐条删除或替换，复刻稿中不出现 |

## 5-beat 节拍（默认 15s，可合并镜）

| 节拍 | 原片任务 | 本品复刻要求 |
|-|-|-|
| **Hook（0–3s）** | 停住划走：场景 + 痛点 / 反差 | 用本品真实痛点或结果画面开场，钩子台词 ≤18 字，第一帧出商品或痛点 |
| **Problem（3–5s）** | 放大痛点或旧方案失败（可与 Hook 合并） | 用本品目标人群的真实场景放大，不虚构问题 |
| **Solution（5–8s）** | 产品亮相 + 一句话是什么 | 白底或场景亮相，一句话说清是什么，品牌放第 2 镜 |
| **Proof（8–13s）** | 1–2 个可被看见的证明（演示 / 对比 / 细节） | 只写用户确认过的卖点，能演就不靠口播数字 |
| **CTA（13–15s+）** | 行动号召 + 贴纸；末镜 min ≥ 3s 方便点 | 口语化引导，避免口号式 CTA 与虚假紧迫 |

## 三个复刻角度（先出角度，用户选定再写全稿）

| 角度 | 怎么做 | 适合 |
|-|-|-|
| **A 保守同构** | 5-beat、钩子类型、证明方式都对齐源结构，只换商品与真实卖点 | 想要最接近「爆款手感」 |
| **B 同构换钩子** | 节拍与证明不变，钩子换成另一类型（走 hook-3s-script 出 6–10 版再选） | 同品类已经有人仿拍过同一钩子 |
| **C 同构换证明** | 节拍与钩子不变，证明从「口播数字」改成「演示 / 对比」，或反过来 | 有实拍素材但卖点数字测不全 |

## 其他拆片路径（工具化逆向，仅借结构）

除 viral-remake 的人工 8 维拆解外，还有工具化逆向路径：自动下载 / 转写 / 抽帧后产出结构分析。工具只负责把原片拆开，**我们只借结构与节奏，不搬运台词 / 口播、不点名原片、不虚构实测**。

- **claude-skill-douyin（待核）**：按转述为抖音短视频逆向拆解技能——无水印下载、ASR 把台词转写、拆开头钩子 / 情绪反转点 / 互动引导词、归档素材库。本次未检索到可验证的仓库地址与原文，功能细节待核，不据转述补全。
- **tiktok-targeted-analysis（待核）**：公开技能目录（skills.rest、LobeHub）可查到 tinnlo/lukas_9688 的收录条目，仓库本体本次未直接访问核对；按收录页描述为 5 阶段流程——元数据提取 → 2 秒间隔抽帧 / 音频转写 → 结构 / 内容 / 策略 / 角色分析 → 复刻脚本 → AI 视频提示词，支持 CSV 批量。具体以仓库原文与收录页为准，细节待核。
- **共同边界**：工具化逆向同样只借结构、节拍与镜头语言；台词、口播、品牌梗一律重写；AI 生成内容与合作关系按平台要求标注。
- **延伸工具（不展开）**：Hypit、镜序 jingxu、awesome-seedance 等重型 AI 视频 / 提示词项目仅作延伸了解，不在本库展开。

## 复刻映射规则（合规边界）

- **只借结构不照搬台词**：节拍、情绪弧线、证明类型、花字节奏可以留；台词、画面、品牌梗全部重写。
- **不搬运口播**：不复制源视频的口播原文、花字原句、配乐、成片画面；只迁移结构、节拍、证明类型（与「成片不引用他人口播」口径一致）。
- **不点名原片**：台词与字幕不提原片账号、品牌、作者；对比用「普通款 / 之前那只」，不贬低具名竞品。
- **不虚构实测**：源片里的销量、评分、认证、时长、温度等数字一律删除，只写用户确认过的真实卖点；没测过的效果用可视化演示代替口头数字。
- **素材分级与补料**：缺图镜头标 TODO，素材按 A/B/C/D 分级建档，补齐后再渲染。
- **过既有自检**：复刻稿同样走四维自检——广告法违规词、卖点有据、资料齐全、虚假紧迫与千川审核风险。

**合规红线（viral-remake 原文）：**禁止最、第一、顶级、国家级、100%、根治及无法证明的销量 / 评分 / 认证；禁止贬低具名竞品；禁止编造测过的时长、温度、泄漏等数据，演示卖点必须用户确认可拍到；不复制源视频画面、配乐、花字原句、口播原文；平台广告与带货标识规则以官方最新说明为准。

# 结尾引导方式

千川素材原生化之后，尾部引导逐步软化，不再使用鲁班时代「现在点击 XX 下单，再送 XX」的极明示指令。常用引导方式：

| 引导方式 | 做法 | 注意 |
|-|-|-|
| **饥饿营销** | 强调库存 / 批次有限，催即刻下单 | 「最后几件」「仅此一天」必须真实可举证，否则属虚假紧迫 |
| **优惠诱导** | 价格锚点、买送件数、套餐加码、满减算账 | 价格、赠品以活动实际为准，不虚构 |
| **点名人群 / 艾特人群** | 「有老公的赶紧去抢」「宝妈听我说」式定向 | 人群与品类要搭，不强行圈人 |
| **身份推荐** | 以自用、回购、过来人身份推荐收口 | 语气随口，不说口号式 CTA |
| **从众引导 / 羊群效应** | 「大家都在买」「已拼 N 单」式社证 | 数据真实，不编造销量与拼单 |
| **附加价值 / 背书引导** | 赠价值、保障承诺、权威背书收口 | 保障条款要能兑现 |
| **痛点引导** | 回扣开头痛点，给出解决出路 | 首尾呼应，不重复念卖点 |

口播结尾要口语化、随口：「反正链接我放这了」式，避免「谢谢观看」结束信号与口号式 CTA；剧情类结尾在高潮处戛然而止或抛悬念，不破坏沉浸感。

# 四维内容自检清单（逐条过）

## 维度一：广告法违规词 / 绝对化用语自检

ClipForge 的广告法检查把风险词分四类，写完脚本逐句扫描口播与花字：

| 类别 | 风险词示例 | 处置建议 |
|-|-|-|
| **绝对化用语** | 最佳、最好、最强、最高级、国家级、世界级、顶级、极致、100%、百分百、万能、史上最、无敌、销量第一、全网第一、排名第一、行业第一、独一无二、领导品牌、王牌、首选品牌、最低价、全网最低价、史上最低、销量冠军、第一品牌 | 《广告法》第 9 条禁用；改为「之一 / 较 / 更 / 深受喜爱」等相对表述 |
| **医疗 / 虚假功效** | 根治、包治、治愈、药到病除、立竿见影、三天见效、七天见效、永不复发、彻底根除、疗效、抗癌、消炎、杀菌、处方药、药妆、医学级、医疗级、特效药 | 普通商品不得宣称医疗 / 治疗 / 根治功效，删除或改为真实体验描述 |
| **需认证宣称** | 纯天然、零添加、无添加、有机食品、100% 天然 | 需权威认证或检测依据，无依据删除 |
| **虚假紧迫** | 最后一天、仅此一天、错过不再有、马上涨价、明天恢复原价、最后几件、最后几单 | 虚假限时限量属平台违规营销（限流 + 处罚）；非真实可举证活动删除，真实活动保留凭证 |

## 维度二：卖点有据（防编造）

- 逐条对照输入资料：功效、参数、价格、背书、认证都必须有来源，资料没有的不写。
- 数字类（时长、容量、含量、折扣、销量、回购率、排名）只使用实测或可查证值，宁可删掉。
- 对比必须真实可测；没测过的效果用可视化演示代替口头数字，不要硬编。
- 背书（名人、权威、销量、评价）不虚构，无授权不挪用。

## 维度三：资料齐全性（缺什么补什么）

- 开拍 / 写词前检查：商品信息、真实卖点、目标人群与场景、可用素材、活动价格机制是否齐备。
- 素材按 A/B/C/D 分级建档；缺哪个等级的素材，先列出补料清单再写，不硬凑。
- 缺素材的镜头在分镜表标 TODO，并给拍摄 / 生成建议；单图素材用不同 motion / fit 补镜。
- 价格、赠品、库存、活动期限必须与商家实际活动一致后才写入。

## 维度四：千川审核风险表达

- 不点名贬低竞品，对比用「普通款 / 某价位常见款」；公平对比见对比评测模板。
- AI 生成内容按平台要求标注；AI 配音同样需要标识。
- 合作 / 赠品测评按平台要求标注「广告 / 合作」。
- 不使用虚假紧迫、虚假限时限量、虚假库存；不引导站外违规交易。
- 口播引用：成片不引用他人视频的口播台词，避免搬运与版权风险。
- 用户给的文案只用于匹配画面，不擅自改写文案内容；画面按文案含义匹配，不替文案加功效。

在现有 6 条日常检查项之外，按七类审核风险逐条过一遍口播、花字与画面；绝对化用语与虚假限时限量已在「维度一」列词，此处只挂接不重复。

| 风险类别 | 典型表现（自检要点） | 依据与处置口径 |
|-|-|-|
| **1 虚假宣传 / 功效虚假** | 虚构功效、夸大效果、保证性承诺（一定见效 / 包好）；暴力测试式虚假实验；使用效果前后对比展示；虚构服务与不当承诺 | 星图违规案例（千川）：虚假实验须不超出常识；投放不得涉及使用产品前后效果对比；《反不正当竞争法》第五章第八条，食品仅饱腹、解渴等作用。处置：删除或改为有证据的真实体验描述 |
